☁️ Simpan Perubahan ke Website

Perubahan langsung tampil di website begitu disimpan — tidak perlu unduh file atau buka GitHub.

Cadangan: unduh sebagai file (mode offline)

  1. Buka repo GitHub website ini lewat browser (bukan aplikasi, lewat github.com).
  2. Masuk ke folder js, klik file yang mau diganti.
  3. Klik ikon pensil (Edit), hapus isinya, tempel isi file hasil unduhan (buka pakai Notepad/TextEdit, salin semua isinya).
  4. Scroll ke bawah, klik tombol hijau "Commit changes". Situs otomatis ter-update dalam 1-2 menit.

Kalau ada foto baru: masuk ke folder assets/images/... yang sesuai, klik "Add file" → "Upload files", seret foto ke sana, lalu Commit changes juga.
